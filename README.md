# OmniAssist Landing Page

Landing page bertema "AI dan Implementasi AI di Industri Contact Center".
Dibuat dengan HTML, CSS, dan JavaScript vanilla, tanpa framework dan tanpa aset eksternal
selain font Plus Jakarta Sans dari Google Fonts.

Nama produk, alamat, email, dan telepon pada halaman ini fiktif untuk keperluan studi kasus.

## Struktur

    index.html       struktur halaman (HTML semantik)
    css/style.css    token desain, komponen, dan aturan responsif
    js/script.js     menu navigasi mobile

## Menjalankan

Buka `index.html` di browser. Tidak perlu proses build.
